# Missile_Command
Clone do clássico arcade Missile Command (1980). Defenda 6 cidades de um bombardeio incessante de mísseis balísticos usando suas baterias de defesa antimísseis. Calcule o tempo de viagem dos projéteis e use ondas de choque para destruir as ameaças. Gameplay retrô com ondas progressivas e limite de munição.

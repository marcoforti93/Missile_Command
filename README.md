# Missile Command Clone 🚀💥

Uma releitura fiel do clássico jogo arcade **Missile Command** (1980). O objetivo é defender suas seis cidades de um bombardeio incessante de mísseis inimigos usando suas baterias de defesa antimísseis.

## 🕹️ Como Jogar

* **Mover a Mira:** Use o [mouse / setas do teclado] para mirar nos alvos.
* **Disparar:** Pressione [botão esquerdo do mouse / Espaço] para lançar um míssil de defesa.
* **Estratégia:** Seus mísseis criam uma onda de choque ao explodir. Calcule o tempo de viagem do projétil para pegar os inimigos no raio da explosão!

## ✨ Funcionalidades

* **Dificuldade Progressiva:** Ondas de mísseis cada vez mais rápidas e numerosas.
* **Sistema de Pontuação:** Multiplicadores baseados nas cidades sobreviventes e munição restante.
* **Gerenciamento de Recursos:** Estoque limitado de mísseis de defesa por rodada.
